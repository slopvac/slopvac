## Examples

Example with [`docland`](https://github.com/denoland/docland):
```
// deno.json
{
    "scripts": {
        "build": "deno run --config deno.jsonc --import-map import-map.json --allow-read=. --allow-write=./static --allow-net build.ts"
    }
}
```

```
$ deno script
```
